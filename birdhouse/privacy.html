Informativa privacy - Birdhouse Camera

Ultimo aggiornamento: 25 ottobre 2026

Chi siamo

Birdhouse Camera è un progetto personale e non commerciale di Matteo Filippi. Il software ("l'applicazione") gira esclusivamente su un dispositivo Raspberry Pi di proprietà dell'autore, installato in una casetta nido, e trasmette in diretta su YouTube le immagini del nido. Contatto: matteofilippi1@gmail.com.

Uso dei dati Google / YouTube

L'applicazione utilizza le API di YouTube (YouTube Data API v3) esclusivamente per gestire le dirette del canale del proprietario: verificare se una diretta è attiva, crearne una nuova dopo un'interruzione, collegarla alla chiave di trasmissione, mandarla in onda e impostarne titolo, descrizione e miniatura.

  • L'autorizzazione viene concessa solo dal proprietario del canale, tramite la procedura ufficiale di Google.
  • Non vengono letti, raccolti o elaborati dati di altri utenti, iscritti o spettatori.
  • Nessun dato viene venduto, condiviso con terze parti o usato per pubblicità.
  • Il token di autorizzazione è conservato solo sul dispositivo e non viene trasmesso altrove, salvo che ai server di Google per le chiamate alle API.

L'uso delle informazioni ricevute dalle API di Google rispetta la Google API Services User Data Policy, inclusi i requisiti di Limited Use.

Immagini trasmesse

La telecamera inquadra esclusivamente l'interno di una casetta nido per uccelli, situata in una proprietà privata. Non riprende persone né aree pubbliche.

Spettatori della diretta

La diretta è pubblicata su YouTube: per la visione si applicano l'informativa privacy e i termini di servizio di YouTube e Google (policies.google.com/privacy). Questo sito non utilizza cookie propri né strumenti di tracciamento.

Revoca dell'accesso

L'accesso concesso all'applicazione può essere revocato in qualsiasi momento da myaccount.google.com/permissions. Dopo la revoca il token conservato sul dispositivo smette di funzionare e viene eliminato.
